Tiletop

Put phones and tablets side by side on a table and turn them into one big game board.

I'm the game master

  1. The game master opens a table and gets a 6-character code.
  2. Everyone else opens this page and joins with the code. Use the same Wi-Fi.
  3. Lay the devices next to each other. The game master arranges the screens, then everyone lines up the pattern on their own screen.
  4. Play chess on the big board. Pieces can be dragged from one screen to the next.

Tip: turn off auto-rotate and use fullscreen. On iPhone, use Share → "Add to Home Screen".
