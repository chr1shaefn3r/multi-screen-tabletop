# Chess pieces

(e.g. https://commons.wikimedia.org/wiki/File:Chess_klt45.svg) and multi-licensed by the author
(GPLv2+, BSD, GFDL). Files taken from lichess' chessground package (`assets/chessground.cburnett.css`).
